# Offline Field Library

A private, offline-first library for field manuals, notes, and reference documents. It indexes
PDF, plain-text, Markdown, and RST files into one portable SQLite database, searches them with a
hybrid of keywords and local embeddings, and asks a local Ollama model to answer with source
citations.

This is the first working MVP. Once Ollama and the models have been downloaded, normal ingestion,
search, and chat do not require an internet connection.

## What works

- Recursive ingestion of `.pdf`, `.txt`, `.md`, `.markdown`, and `.rst` files
- Page-aware PDF citations
- Incremental updates: unchanged files are skipped by SHA-256 content hash
- SQLite FTS5 keyword search with no model dependency
- Semantic search using embeddings generated by local Ollama
- Hybrid ranking that combines keyword and semantic result order
- One-shot questions and a multi-turn terminal chat
- Grounded prompts that tell the model to use only retrieved excerpts and cite `[1]`, `[2]`, etc.
- A single `.field-library/index.sqlite3` file that is easy to copy or back up

## Quick start

Prerequisites: Python 3.12+, [uv](https://docs.astral.sh/uv/), and
[Ollama](https://ollama.com/) running locally.

```bash
uv sync
ollama pull nomic-embed-text
ollama pull llama3.2:3b
```

Index a file or a whole folder:

```bash
uv run offline-field-library ingest ./path/to/field-documents
```

Search the library:

```bash
uv run offline-field-library search "water purification procedure"
```

Ask one cited question:

```bash
uv run offline-field-library ask "How should we purify water in the field?"
```

Start an ongoing chat:

```bash
uv run offline-field-library chat
```

Type `/exit` to leave chat. Every answer prints the retrieved file paths and PDF page numbers
under `Sources`.

## Keyword-only mode

The core index and search work without Ollama. This is useful on a small device or while setting up
models:

```bash
uv run offline-field-library ingest ./documents --no-embeddings
uv run offline-field-library search "radio check" --keyword-only
uv run offline-field-library ask "When is the radio check?" --keyword-only
```

`ask` and `chat` still need a local chat model; `--keyword-only` only disables semantic retrieval.

## Library and model options

The default index lives at `.field-library/index.sqlite3`. Select another portable library with
`--library`, or set `OFL_LIBRARY` once for all commands:

```bash
export OFL_LIBRARY=/Volumes/FIELD/reference-library
uv run offline-field-library ingest ./documents
uv run offline-field-library status
```

Choose other installed Ollama models when needed:

```bash
uv run offline-field-library ingest ./documents --embedding-model mxbai-embed-large
uv run offline-field-library chat --model llama3.1:8b
```

Keep one embedding model per library. Vector dimensions and meaning differ across models, so the
application rejects an accidental model mix. To change embedding models, create a new library
folder and ingest again.

Other useful commands:

```bash
uv run offline-field-library init
uv run offline-field-library status
uv run offline-field-library --help
uv run offline-field-library ingest --help
```

Running `ingest` again updates changed files and skips unchanged ones.

## Architecture

```text
PDF / text / Markdown / RST
            |
     extraction + cleanup
            |
 page-aware overlapping passages
            |
    +-------+----------------+
    |                        |
SQLite FTS5              Ollama embeddings
    |                        |
    +---- reciprocal-rank ---+
             fusion
               |
       top cited passages
               |
        local Ollama chat
```

- `documents.py` discovers files, extracts text, and creates deterministic overlapping passages.
- `ingestion.py` hashes inputs, batches embeddings, and atomically replaces each changed document.
- `database.py` owns the SQLite schema, FTS5 index, metadata, and compact float32 vector storage.
- `retrieval.py` performs keyword search and exact cosine similarity, then combines their ranks.
- `rag.py` builds the grounded prompt and stable numbered source map.
- `cli.py` exposes initialization, ingestion, status, search, ask, and chat workflows.

Exact vector scanning is intentional in this MVP: it has no external vector-database dependency and
is fast enough for a modest field library. A later version can add an approximate vector index
without changing the ingestion or chat interfaces.

## Testing and quality checks

Tests use a deterministic fake model, so they do not need Ollama or network access:

```bash
uv run pytest
uv run ruff check .
```

For a quick manual test without any model:

```bash
uv run offline-field-library ingest README.md --library /tmp/ofl-demo --no-embeddings
uv run offline-field-library search "hybrid ranking" --library /tmp/ofl-demo --keyword-only
```

## MVP limits

- Scanned/image-only PDFs need OCR before ingestion.
- Deleting a source file does not yet remove its prior index entry.
- Semantic search scans all stored vectors, so very large corpora will need an ANN index.
- Answers are grounded by prompting and citations, but local model quality still varies. Verify
  critical field decisions against the cited source document.
